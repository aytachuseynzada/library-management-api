# Library Management System

## Description
REST API for managing authors, books and members.

## Technologies
- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Swagger OpenAPI

## Running the project

1. Clone repository
2. Configure database properties
3. Run the application from your IDE


## API Documentation

Swagger UI:
http://localhost:9999/swagger-ui/index.html


## Endpoints

### Authors

GET /authors
GET /authors/{id}
POST /authors
PUT /authors/{id}
DELETE /authors/{id}

### Books

GET /books
GET /books/{id}
POST /books
PUT /books/{id}
DELETE /books/{id}

### Members

GET /members
GET /members/{id}
POST /members
PUT /members/{id}
DELETE /members/{id}
